# Start here

Open the [practice page](https://kiankyars.github.io/piano/). A four-bar exercise is already on the page.

1. Start at **level 1**. Find the first right-hand and left-hand notes; C4 is middle C. The right hand stays within C4–G4 and the left within C3–G3.
2. Check the meter, notes and rests. Choose a slow pulse and count yourself in.
3. Play once without restarting. Keep counting while a hand rests. Small errors can wait until the end.
4. Check the first attempt. If unsure what it should sound like, use **Hear it** now. Repair one problem, then choose **Next exercise**.

Repeat this during **30 minutes of reading**, then spend **30 minutes on your pieces**. The page uses conventional five-line treble and bass staves throughout, without printed fingering or note names.

If you keep stopping, try one hand or two bars first, then return to the full exercise. If several new exercises are comfortably fluent, sample the next level. A level is a practice setting, not a daily assignment or a grade.

Your next practice can start the same way. Read the displayed exercise, check it, and continue to the next one. No score-library browsing is required.
